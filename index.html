أولاً: سياسة الخصوصية (النسخة العربية)

1. مقدمة والتزام الشفافية

توضح سياسة الخصوصية هذه كيفية تعامل تطبيق Smart Real VPN (المطور والمنشور بواسطة Novyra) مع البيانات والأذونات على أجهزة Android. يعمل التطبيق على توفير نفق شبكة افتراضية خاصة (VPN) مشفر عبر بروتوكول OpenVPN دون الحاجة إلى إنشاء حساب أو تسجيل دخول.

2. إفصاح استخدام خدمة VpnService في أندرويد

يستخدم التطبيق واجهة برمجة التطبيقات الرسمية android.net.VpnService لإنشاء نفق شبكي مشفر بين جهاز المستخدم وخادم الـ VPN المختار بهدف حماية حركة البيانات على الشبكات العامة. لا يقوم المطور (Novyra) بتشغيل خوادم خاصة لتخزين أو بيع أو مراقبة محتوى تصفحك.

3. البيانات المخزنة محليًا على جهازك فقط

لا يطلب التطبيق أي بيانات شخصية كالاسم أو البريد الإلكتروني أو رقم الهاتف. يتم حفظ التفضيلات التالية محليًا على جهازك فقط (SharedPreferences وذاكرة التطبيق الداخلية):

  • معرّف الخادم المختار وقائمة الدول المفضلة.
  • إعدادات مزود DNS المختار (Cloudflare أو AdGuard أو Quad9 أو Google DNS).
  • قائمة حزم التطبيقات المحددة محليًا في ميزة تقسيم النفق (Split Tunneling).
  • نسخة مؤقتة مضغوطة من دليل الخوادم العامة لتسريع تشغيل التطبيق.
  • سجل تشخيص الجلسة الحالية (يُعرض داخل نافذة التشخيص في الذاكرة المؤقتة فقط ولا يُرسل للمطور).

4. خدمات الطرف الثالث والبيانات التي قد تعالجها

  • إعلانات Google AdMob (com.google.android.gms:play-services-ads): يستخدم التطبيق خدمة Google AdMob لعرض إعلانات البانر وإعلانات المكافأة (Rewarded Ads) لفتح خوادم VIP مجانًا. قد تجمع مكتبة AdMob تلقائيًا معرّف الإعلانات (Advertising ID / AD_ID)، وعنوان IP لتقدير الموقع التقريبي، وبيانات الجهاز والتشخيص والتفاعل مع الإعلانات. راجع سياسة خصوصية Google.
  • دليل وخوادم شبكة VPN Gate العامة (vpngate.net): يجلب التطبيق قائمة الخوادم العامة من مشروع VPN Gate Academic Public VPN Relay التابع لجامعة تسوكوبا. عند الاتصال بأحد خوادم VPN Gate التطوعية، تمر حركة المرور عبر ذلك الخادم وتخضع لسياسة مشغلي خوادم VPN Gate لمكافحة إساءة الاستخدام (حيث قد يحتفظ مشغلو الخوادم بسجلات الاتصال التقنية كعنوان IP وطابع الوقت لمدة أسبوعين 2 Weeks). لا يملك المطور Novyra أي وصول لتلك الخوادم أو سجلاتها.
  • مزودو خدمة DNS الاختياريون: تُوجَّه استعلامات DNS داخل النفق إلى المزود الذي يختاره المستخدم: Cloudflare (1.1.1.1)، أو AdGuard DNS (94.140.14.14)، أو Quad9 (9.9.9.9)، أو Google DNS (8.8.8.8).

5. الأذونات المطلوبة والغرض منها

  • android.net.VpnService و FOREGROUND_SERVICE و FOREGROUND_SERVICE_SPECIAL_USE: لإنشاء نفق OpenVPN المشفر وإبقائه نشطًا في الخلفية.
  • QUERY_ALL_PACKAGES: يُستخدم محليًا على جهازك فقط لعرض قائمة التطبيقات المثبتة داخل إعدادات Split Tunneling لتحديد التطبيقات التي تمر عبر الـ VPN. لا يتم رفع قائمة تطبيقاتك لأي خادم خارجي نهائيًا.
  • INTERNET و ACCESS_NETWORK_STATE و ACCESS_LOCAL_NETWORK: لجلب قائمة الخوادم وقياس البينج الفعلي (TCP Ping) وإنشاء نفق الاتصال.
  • POST_NOTIFICATIONS: لإظهار إشعار حالة الاتصال الدائم وأزرار الإيقاف والاستئناف.
  • RECEIVE_BOOT_COMPLETED: لدعم إعادة الاتصال التلقائي في وضع Always-On VPN بعد إعادة تشغيل الجهاز.

II. Privacy Policy (English Version)

1. Overview & Controller Information

This Privacy Policy describes how Smart Real VPN (package name: com.smartreal.vpn), developed and published by Novyra, handles data and system permissions on Android. Smart Real VPN provides an encrypted OpenVPN tunnel without requiring user registration or personal accounts.

2. Android VpnService Usage

Smart Real VPN uses Android's official android.net.VpnService API to create an encrypted network tunnel to protect your traffic on public Wi-Fi and untrusted networks. Novyra does not operate proprietary logging servers to collect, store, or sell your browsing history or traffic payload.

3. Information Stored Locally on Your Device

  • Selected server ID and favorite country codes (SharedPreferences).
  • Selected DNS provider mode (Cloudflare, AdGuard, Quad9, or Google DNS).
  • Split Tunneling selected app package names (stored strictly on-device).
  • Local compressed cache of the public server directory (vpn_gate_servers_v2.cache).
  • Ephemeral session handshake logs displayed only in the in-app Diagnostics dialog.

4. Third-Party Services & Data Collection

  • Google AdMob (com.google.android.gms:play-services-ads): Used to display banner ads and optional rewarded ads (to unlock VIP server selections). Google Mobile Ads SDK may automatically collect your Android Advertising ID (AD_ID), IP address (for coarse location and fraud prevention), device information, and ad interaction/diagnostic data in accordance with Google's Privacy Policy.
  • VPN Gate Public Relay Network (vpngate.net): The app retrieves public OpenVPN server listings from the VPN Gate Academic Public VPN Relay Project (https://www.vpngate.net/api/iphone/). When you connect to a community server, traffic traverses that server operator's node and is subject to VPN Gate's anti-abuse policy (under which operators may retain connection metadata logs for up to 2 Weeks). Novyra does not control or access third-party volunteer servers.
  • Optional Public DNS Resolvers: DNS queries inside the VPN tunnel are routed to your chosen DNS provider: Cloudflare (1.1.1.1), AdGuard DNS (94.140.14.14), Quad9 (9.9.9.9), or Google Public DNS (8.8.8.8).

5. Permissions Disclosure

  • android.net.VpnService, FOREGROUND_SERVICE, FOREGROUND_SERVICE_SPECIAL_USE (vpn): Core permissions required to run the encrypted OpenVPN tunnel in the background.
  • QUERY_ALL_PACKAGES: Used 100% locally on your device to list launchable installed apps inside the Split Tunneling feature so you can choose which apps use the VPN tunnel. Your installed app list is never transmitted off your device.
  • INTERNET, ACCESS_NETWORK_STATE, ACCESS_LOCAL_NETWORK: Used to fetch server lists, measure real-time TCP latency (Ping), and establish VPN connections.
  • POST_NOTIFICATIONS: Displays the active VPN session notification and quick controls.
  • RECEIVE_BOOT_COMPLETED: Supports system Always-On VPN reconnection on device boot.

6. Data Deletion & User Rights (GDPR / KVKK)

You can delete all local app data at any time via Android Settings → Apps → Smart Real VPN → Storage → Clear Data or by uninstalling the application. You may also reset your Advertising ID or opt out of personalized ads in Android Settings → Google → Ads.
